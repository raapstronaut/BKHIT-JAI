# Website BKHIT Lampung — Jenis Asing Invasif (Multi-page)

Website ini sudah diubah dari landing page satu halaman menjadi situs multi-page.

## Halaman

- `index.html` — Home
- `tentang.html` — Tentang JAI, timeline, regulasi/PDF, tujuan, wilayah kerja
- `jai.html` — Kajian JAI pada ikan, tiga pilar, kategori, database ringkas spesies
- `galeri.html` — Galeri monitoring dengan lightbox
- `blog.html` — Artikel dan publikasi

## Menjalankan

1. Extract ZIP.
2. Buka folder di VS Code.
3. Klik kanan `index.html` → **Open with Live Server**.
4. Alternatif: klik dua kali `index.html`, tetapi Live Server lebih aman untuk navigasi dan aset.

## Mengganti logo

Ganti file `assets/images/logo-placeholder.svg` dengan logo resmi. Pertahankan nama file atau ubah semua referensi HTML.

## Menambahkan PDF regulasi

Buka folder `assets/pdf/` dan ikuti `README.txt`.

## Mengganti gambar galeri

Ganti file SVG berikut dengan JPG/PNG kegiatan resmi, kemudian sesuaikan ekstensi pada `galeri.html`:

- `gallery-identifikasi.svg`
- `gallery-pemeriksaan.svg`
- `gallery-monitoring.svg`
- `gallery-sampling.svg`
- `gallery-lalu-lintas.svg`
- `gallery-edukasi.svg`
- `gallery-biosekuriti.svg`
- `gallery-dokumentasi.svg`

## Catatan penting

Konten regulasi, tanggal artikel, nama spesies, dan uraian mengikuti materi yang diberikan pengguna. Lakukan verifikasi substansi dan gunakan logo/foto resmi sebelum website dipublikasikan sebagai kanal instansi.
